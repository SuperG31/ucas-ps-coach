## Goal
Build an AI tool that fixes Clifton's **UCAS personal-statement & reference** workflow — a structured intake that drafts UCAS-aligned statements (and teacher references) via Google Gemini, inside a Canva app embedded in Google Sites, enforcing a single sequential feedback channel. *(Pivoted June 2026 — see Stakeholder-Steer-2026-06.)*

## Why
To build a genuine, technically credible project for the personal statement when applying to university — specifically HKUST's Physics and AI programme. Admissions want evidence of initiative and applied AI thinking, not just grades. *(Bonus: leadership noted the project is itself exactly the "above and beyond" material that strengthens a PS + reference.)*

## Tangible Outcomes
- A working **Gemini + Canva** prototype embedded in Google Sites
- An enforced sequential feedback workflow (Student → Teacher A → Student → Teacher B)
- A closed pilot (5–10 students + tutors) with feedback on accuracy, tone, friction
- A data-handling note (no external egress) signed off by School IT
- Documentation of the process suitable for a Physics + AI personal statement

## Open Problems
1. Intake schema — exact PS + reference fields that produce good drafts
2. Prompt design — UCAS-aligned + Clifton flavour, coaching toward academic passion over generic extracurriculars
3. Workflow enforcement — building the sequential review channel in Canva / Google Sites
4. Stakeholder sign-off — School IT (deployment), Nick the UCAS Adviser + housemasters (content)
5. Pilot + impact measurement compelling for a Physics + AI application
